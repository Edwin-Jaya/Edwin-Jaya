## 👨‍💻 About Me

I build AI systems that run in production. At **BCA Finance**, I work as an IT Management Trainee (AI & Software Engineer), where I've built:

- A **text-to-SQL RAG system** that lets executives query company data in natural language (in pilot)
- An **AI document-verification pipeline** for financing agreements (OCR + self-hosted LLM), cutting turnaround from 15 to 5 days
- A **full-stack lending platform** (Angular, Spring Boot, Kotlin) deployed on GCP with CI/CD

Before that, I spent 2.5 years at **UNIKOM CodeLabs**, growing from Data Lab Assistant to **AI Research Team Lead**.

🏆 **Highlights:** Google Solution Challenge 2024 Global Top 100 · APICTA 2024 Asia Pacific Finalist · PKM-KI 2024 National Grant  
📍 **Location:** Jakarta, Indonesia · Open to relocation  
🔨 **Currently building:** [MiniHarness](https://github.com/Edwin-Jaya/reyna-miniharness), an AI agent harness written from scratch in Python

## 🚀 Featured Projects

### 🤖 [MiniHarness](https://github.com/Edwin-Jaya/reyna-miniharness) · *in progress*
> An AI agent harness built from scratch in Python to understand agent loops, tool use, and evaluation from first principles.
- **Done:** core agent loop, tool system, tests
- **Next:** evaluation harness

### 🔍 [RAG-Powered PDF QA System](https://github.com/Edwin-Jaya/RAG-Powered-PDF-QA-System)
> Turns PDFs into searchable knowledge: chunking, embeddings, vector search in Qdrant, and context-grounded answers from an LLM, with a Streamlit demo.
- **Tech:** Python, Qdrant, LM Studio (nomic-embed-text-v1.5), GPT-OSS, Streamlit, Poetry
- [🔗 Live demo](https://rag-powered-pdf-app.streamlit.app)

### 📊 Socialabs · *APICTA 2024 Asia Pacific Finalist*
> X (Twitter) analytics platform with embedded topic modeling (replacing LDA), sentiment and network analysis, LLM-generated topic summaries, and a RAG chatbot over collected tweets. Led the team.

### ♻️ Doko · *Google Solution Challenge 2024 Global Top 100*
> Waste-classification app: a TensorFlow image classifier deployed via ONNX in Unity. Across 300 students in 5 elementary schools, the share who could sort waste correctly rose from 35% to 65%.
